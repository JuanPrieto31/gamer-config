# Agentes del proyecto

Adaptados de las skills de `~/.agents/skills` (security-and-hardening, code-review-and-quality, debugging-and-error-recovery, test-driven-development, shipping-and-launch) a Gamer Config.

| Agente | Para qué |
|---|---|
| `revisor-seguridad` | Auditar borrado de archivos, IPC, procesos y red |
| `revisor-codigo` | Revisión de diffs con las convenciones del repo |
| `depurador` | Causa raíz de detección, portadas, ajustes y limpieza |
| `qa-electron` | Pruebas sin tocar juegos reales |
| `lanzador` | Versión, instalador y release (sin publicar solo) |
